# Hello Codex

A small, dependency-free Node.js web project that serves a friendly **Hello Codex** page.

## Requirements

- Node.js 18 or newer

## Run locally

```bash
npm start
```

Then open [http://127.0.0.1:3000](http://127.0.0.1:3000) in your browser.

## Project layout

- `index.js` — HTTP server and page markup
- `package.json` — project metadata and run script
